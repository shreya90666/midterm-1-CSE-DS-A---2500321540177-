# Student Library Management System

A simple Library Management System developed using HTML, CSS and JavaScript with Node.js. It allows users to manage books using CRUD operations.

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js

## Topics Covered
- HTTP Server
- REST API
- CRUD Operations
- JSON Data Handling
- URL Routing
- Search and Filter
- File System Module

## Functions and Methods Used
- `http.createServer()` – Creates the HTTP server.
- `server.listen()` – Starts the server.
- `fs.readFile()` – Reads files.
- `books.filter()` – Filters books.
- `books.find()` – Finds a book by ID.
- `books.push()` – Adds a new book.
- `books.splice()` – Deletes a book.
- `JSON.stringify()` – Converts data into JSON.
- `JSON.parse()` – Converts JSON into JavaScript objects.
- `GET, POST, PUT, DELETE` – Performs CRUD operations.

## Features
- View all available books.
- Search books by title, author or category.
- Add new books.
- Update book details.
- Delete books.
